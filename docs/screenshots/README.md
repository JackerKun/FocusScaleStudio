# Focus Scale Studio 截图

真实界面，使用内置目录和演示机械参数。校准点不是实测数据；未勾选“我已实测”确认框。打印 / SVG 的禁用提示保留，不把截图作为物理尺寸或镜头精度依据。浏览器上下文独立，不读取个人保存的方案。

包含工作区、镜头搜索、校准输入、多圈预览、使用指南，以及手机参数 / 预览两张图片。生成记录见 `capture-report.json`，包含 CSV 与 JSON 真实下载验证结果。

## 复现

维护工具需要 Node.js 20+、Google Chrome；主程序不需要它们。

```bash
cd tools/screenshots
npm ci
npm run capture
```

默认输出到 `docs/screenshots/`，可用 `FOCUSSCALE_SCREENSHOT_DIR` 指定其他目录。工具在随机本机端口启动静态服务，自动操作实际表单，检查页面异常和下载内容，并关闭浏览器及服务器。手机截图前会实际触摸输入框并验证焦点。

更新图片后请逐张检查排版、刻度与文字、错误提示是否完整可见；文档截图不能替代光学单元测试、毛玻璃合焦检查或打印校验。
